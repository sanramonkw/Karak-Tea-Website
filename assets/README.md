# Karak Tea static assets

Brand media for the site, stored in-repo for offline deploys and static hosting.

## Layout

- `fonts/` — Bahij Janna & Helvetica Arabic
- `images/brand/` — logo, logo wordmark
- `images/slider/` — home hero slides (EN/AR)
- `images/home/` — home section photos
- `images/products/` — product pack shots
- `images/flags/` — contact page flags
- `images/preparation/` — how-to banners
- `images/vending/` — vending page banner
- `images/theme/` — leaves pattern, checklist icons

## Updating media

Add or replace files here, then update paths in `js/assets.js` and `css/styles.css` as needed. No download scripts — this folder is the source of truth.
