# Karak Tea — karaktea.com (Astro rebuild)

Modern Astro 5 + Tailwind 4 rebuild of karaktea.com, migrated off WordPress
(bilingual EN/AR with original Arabic slugs, full SEO/GEO layer).

- **Start here:** `CLAUDE.md` (project context & design tokens) and
  `DEPLOYMENT.md` (read before deploying).
- **Run:** `npm install && npm run dev` · build with `npm run build` (static `dist/`).
- **`variants/premium|bold|editorial/`** — three alternative production-ready
  design directions of the same site (same content/URLs/SEO, different visual
  language). Each is a self-contained Astro project with its own `VARIANT.md`.
  The root project is the current master reference.
